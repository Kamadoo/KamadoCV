# KamadoCV

Meu currículo online, feito do zero em HTML e CSS e publicado no GitHub Pages.

**👉 [kamadoo.github.io/KamadoCV](https://kamadoo.github.io/KamadoCV/)** · [versão em inglês](https://kamadoo.github.io/KamadoCV/?lang=en)

> 🇺🇸 My online resume, built from scratch in HTML and CSS and hosted on GitHub Pages. Switch to English with the PT/EN button or `?lang=en`.

## Recursos

- Português e inglês, com troca de idioma no topo (ou pelo link `?lang=en`)
- Botão **Baixar PDF**, com layout próprio para impressão em A4
- Modo escuro automático, seguindo o tema do sistema
- Layout responsivo para celular
- Imagem de pré-visualização para quando o link é compartilhado (LinkedIn, WhatsApp, etc.)

## Estrutura

```
index.html            # conteúdo do currículo nas duas línguas
assets/css/main.css   # estilos (tela, modo escuro e impressão)
assets/font/          # fonte
assets/images/        # logos das instituições e imagem de pré-visualização
```

Não usa framework nem build: é só abrir o `index.html` no navegador.
